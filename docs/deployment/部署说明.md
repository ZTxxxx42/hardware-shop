# 五金商贸 MVP · 部署说明

> 本文给出后端、两个 Web 前端、微信小程序的本地运行与部署步骤。架构拓扑与运维要求见 [../architecture/架构设计.md](../architecture/架构设计.md) 第 6 节。当前仓库**尚未提供 Dockerfile / docker-compose.yml**，Docker 方案按架构设计待补。

## 1. 后端（FastAPI + PostgreSQL）

### 1.1 环境要求

- Python 3.13（架构设计定版，见 CHANGELOG）
- PostgreSQL 16（数据库名默认 `hardware_shop`，连接串见 `.env`）
- 依赖见 `backend/requirements.txt`

### 1.2 本地运行

```bash
cd backend

# 1) 创建虚拟环境并安装依赖
python -m venv .venv
# Windows: .venv\Scripts\activate；Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

# 2) 准备环境变量
cp .env.example .env   # 按需修改 SECRET_KEY / DATABASE_URL / CORS_ORIGINS

# 3) 建表
alembic upgrade head

# 4) 填充种子数据（可重复执行）
python -m scripts.seed

# 5) 启动（开发）
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

启动后可访问：

- 健康检查：`GET http://localhost:8000/healthz`
- OpenAPI 文档：`http://localhost:8000/docs`（FastAPI 自动生成）

### 1.3 生产运行要点

- 生产关闭 `--reload`，建议 `uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers <N>`，外层由 Nginx 反代并终止 TLS。
- 关键环境变量（`backend/.env`）：`DEBUG`、`SECRET_KEY`（必须改）、`DATABASE_URL`、`CORS_ORIGINS`（JSON 数组）、`WECHAT_PAY_API_V3_KEY`、`ALIPAY_APP_PRIVATE_KEY`（支付联调后填写）。
- 数据库备份：PostgreSQL 每日 `pg_dump`；`.env` 与证书需一并备份。

## 2. Web 前端（Vite build）

买家端 `frontend/shop-web/` 与管理端 `frontend/admin-web/` 构建方式一致。

```bash
# 买家端
cd frontend/shop-web
npm install
cp .env.example .env.production   # 配置 VITE_API_BASE_URL 为后端公网地址
npm run build                      # 产物在 dist/

# 管理端
cd frontend/admin-web
npm install
cp .env.example .env.production
npm run build                      # 产物在 dist/
```

Nginx 托管要点（两个 SPA 均为 history 路由）：

```nginx
server {
    listen 443 ssl;
    server_name shop.example.com;   # 按实际域名

    root /var/www/shop-web/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

管理端同理，可用独立域名或子路径挂载（子路径需同步调整 Vite `base` 与路由 `base`）。

## 3. 微信小程序（uni-app）

### 3.1 编译

```bash
cd frontend/mp-shop
npm install

# 微信小程序产物（输出到 dist/build/mp-weixin）
npm run build:mp-weixin

# H5 预览/构建（开发联调用）
npm run dev:h5
npm run build:h5
```

### 3.2 开发者工具导入

1. 打开「微信开发者工具」，选择「导入项目」。
2. 目录选择 `frontend/mp-shop/dist/build/mp-weixin`。
3. AppID 填入真实小程序 AppID（当前 `src/manifest.json` 的 `mp-weixin.appid` 为空，需补填）。
4. 开发期若需跳过域名校验，可在「详情 → 本地设置」勾选「不校验合法域名」；正式上线必须配置合法域名。

### 3.3 上线要点

| 项 | 要求 |
| --- | --- |
| 请求域名 | 小程序后台配置 `request` 合法域名为后端 HTTPS 域名；小程序不支持 IP/HTTP，必须 **HTTPS + 备案域名** |
| 微信登录 | 当前使用账号密码登录（复用 `/api/auth/login`）；微信授权登录（`code` 换 openid）**待接入** |
| 微信支付 | 支付网关为桩实现；微信支付（Native/JSAPI）**待接入**，需商户号、API v3 密钥与回调验签 |
| tabBar 图标 | 已内置 8 张 PNG（见素材清单），无需替换即可用 |
| 版本 | `src/manifest.json` 维护 `versionName`/`versionCode` |

### 3.4 端口说明

- 小程序 H5 开发端口为 `5174`（`src/manifest.json` 的 `h5.devServer.port`），与管理端 Web（`admin-web`，5174）**端口相同**；同时启动两者需先改其一，避免冲突（**待核对/待调整**）。
