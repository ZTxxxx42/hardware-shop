# 五金商贸网站 · 仓库目录结构说明

> 本文件描述仓库目录树与各目录职责，作为维护与新增模块的落位指引。目录以实际代码为准。

## 1. 顶层目录

```text
五金商贸/
├── backend/          # FastAPI 后端（Python）
├── frontend/         # 三个前端（Vue3 SPA × 2 + uni-app × 1）
├── docs/             # 项目文档（本目录）
├── shots/            # 界面样式参考截图
├── .gitignore        # Git 忽略规则
└── .idea/            # PyCharm IDE 配置（已忽略）
```

| 目录 | 职责 |
| --- | --- |
| `backend/` | 后端应用、领域规则、数据模型、迁移、种子数据 |
| `frontend/` | 买家端 Web、管理端 Web、买家端小程序 |
| `docs/` | 全部项目文档，见 [README.md](README.md) |
| `shots/` | `恒泰五金移动端界面.png`、`恒泰五金网页端界面.png` |

## 2. 后端 `backend/`

```text
backend/
├── app/
│   ├── main.py          # FastAPI 应用入口：实例、路由、CORS、全局异常处理、/healthz
│   ├── api/             # 表现层（API Router）：auth/cart/catalog/member/order/admin/payment/router
│   ├── services/        # 应用服务层：用例编排（下单、支付回调、购物车、取价等）
│   ├── domain/          # 领域层：order_state/pricing/inventory/payment 纯规则
│   ├── models/          # SQLAlchemy 2.0 模型（13 张表）
│   ├── schemas/         # Pydantic v2 请求/响应模型
│   └── core/            # 配置、DB 会话、依赖注入、异常、安全（JWT/密码）
├── alembic/             # Alembic 迁移（env.py、versions/0001_initial_schema.py）
├── alembic.ini          # Alembic 配置
├── scripts/seed.py      # 种子数据脚本
├── requirements.txt     # Python 依赖
├── .env.example         # 环境变量模板
└── .env                 # 本地环境变量（已 gitignore）
```

分层职责边界（详见 [architecture/架构设计.md](architecture/架构设计.md) 第 2 节）：

- `api/`：参数校验、鉴权、路由分发、响应封装，不写业务规则。
- `services/`：用例编排（下单 = 校验库存 + 锁价 + 创建订单 + 创建支付单）。
- `domain/`：纯业务规则（分级价格、订单状态机、库存增减、支付幂等判断）。
- `models/`：持久化与关系定义。
- `core/`：基础设施（配置、会话、鉴权依赖、异常、安全）。

## 3. 前端 `frontend/`

### 3.1 `frontend/shop-web/`（买家端 Web）

```text
shop-web/
├── index.html
├── package.json / vite.config.ts / tsconfig*.json
├── .env.development / .env.example
└── src/
    ├── api/             # axios 客户端与 auth/cart/catalog/member/order API
    ├── assets/          # 品牌、分类、商品、场景素材与样式（详见素材清单）
    ├── components/      # 通用组件 + home/ + layout/
    ├── data/            # 首页静态示例数据
    ├── router/          # Vue Router 路由与登录守卫
    ├── stores/          # Pinia：user、cart
    ├── types/           # catalog、shop 类型
    ├── utils/           # catalog 工具
    └── views/           # 页面（首页、分类、商品、购物车、下单、订单、账号等）
```

### 3.2 `frontend/admin-web/`（管理端 Web）

```text
admin-web/
├── index.html
├── package.json / vite.config.ts / tsconfig.json
├── .env.development / .env.example
└── src/
    ├── api/             # axios 客户端、admin 端点、错误处理、mappers
    ├── assets/          # favicon、logo、商品示例素材
    ├── components/      # PageHeader、RequestError
    ├── layout/          # AdminLayout（侧边栏后台布局）

    ├── router/          # 路由与登录守卫
    ├── stores/          # Pinia：auth（管理员登录态）

```
