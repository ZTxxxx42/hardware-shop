# 五金商贸 MVP · 前端文案与组件清单

> 本文列出三个前端的页面、组件、关键文案、状态管理与 API 模块，作为前端维护与文案统一的索引。以 `frontend/` 实际代码为准。素材资产见 [素材清单.md](素材清单.md)。

## 0. 三端概览

| 端 | 目录 | 品牌名 | 技术栈 | 开发端口 | 后端集成状态 |
| --- | --- | --- | --- | --- | --- |
| 买家端 Web | `frontend/shop-web/` | 恒泰五金 | Vue 3 + Vite 6 + Element Plus + Pinia + Vue Router | 5173 | 目录/购物车/下单/订单/账号已接真实 API；部分静态页 |
| 管理端 Web | `frontend/admin-web/` | 恒泰五金 | Vue 3 + Vite 6 + Element Plus + Pinia + Vue Router | 5174 | 登录 + 5 模块已接真实 API；客户管理未接 |
| 买家端小程序 | `frontend/mp-shop/` | 恒泰五金 | uni-app（Vue 3）+ Pinia | h5 5174 | 全部页面已接真实 API |

品牌与视觉：

- 中文品牌名统一为「恒泰五金」；买家端 Web 英文副标 `Hengtai Hardware Trade`。
- 品牌主色 `#1a6fd6`（蓝），深色 `#0c56ad` / `#102b49`；价格色 `#e45b32`（橙红）。
- 管理端 README 标题残留「恒固五金」、登录页英文 `HENGGU HARDWARE`，与 UI 中文「恒泰五金」不一致（**待核对**，见 CHANGELOG 待办）。
