## 4. 素材与数据映射

- 后端 `product.main_image` 存素材标识（种子数据：`bolt`/`nut`/`washer`/`anchor`/`hinge`/`bearing`/`wrench`/`drill`）。
- 前端通过工具函数把标识映射为本地 SVG：shop-web/mp-shop 见 `src/utils/catalog.ts`（`getCategoryIcon` / 商品图映射），管理端见 `src/utils/product.ts`（`resolveProductImage`）。
- 新增商品/分类时：若复用现有素材，直接沿用标识名；若新增素材，需同步到两端买家端 assets 目录并补充映射。
